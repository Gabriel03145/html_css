explicação do projeto

Aqui, nesse projeto, estou criando um site que consiste em ter várias funções, incluindo coisas que eu já vi antes, como criar uma cor de fundo com rodapé, aplicar várias cores, mudar a direção em que a cor vai começar e mudar de pouco em pouco, aplicar links, interação quando clica ou passa o mouse por cima, etc. Para isso vou usar estes comandos:
font-family: vou usar uma família de fonte com estilo android.
background-image: linear-gradient, que vai servir para aplicar uma estética de várias cores no fundo, seguindo uma linha.
text-align: vai servir para alinhar o meu texto no centro, sem que fique muito para os lados.
:hover: para aplicar uma estética que apenas aparece quando passa o mouse por cima.
Também vou usar outros pseudo-elementos, como visited, active, after e before, e outros comandos ou tags que ainda vou usar para melhorar o site e criá-lo. Abaixo usei imagens de praia, baixadas do Pexels.
