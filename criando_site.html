explicação do projeto

aqui nesse projeto, estou criando um site por qual consiste em ter várias funções, incluindo coisas que eu já vi antes, coisas como criar uma cor de fundo com rodapé, aplicar várias cores mudar a direção por qual vai começar a cor e mudar de pouco em pouco, aplicar links, interação quando clica ou passa o mouse por cima e etc. Para isso vou usar esses comandos:
font famil: vou usar uma familia de fonte com estilo android.
background-image: linear gradient que vai servir para aplicar uma estetica de várias cores na background seguindo uma linha text align: vai servir para alinhar o meu texto no centro sem que fique muito em dois lados diferentes tag:hover para aplicar uma estetica que apenas aparece quando passa o mouse por cima outros pseudo-elementos como visited, active, after e before e outros comandos ou tags que ainda vou usar para melhorar o site e cria-lo. abaixo usei imagens de silksong e hollow knight
